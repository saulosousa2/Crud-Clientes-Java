# CRUD de clientes em Java

Aplicando de console em java feita para o cadastro de clientes, sendo usado as 4 funcionalidades de um CRUD que seriam: create,read,update e delete.

O projeto foi desenvolvido com foco em aplicar meu aprendizado de java e buscar ter uma noçao basica de como opera o mercado de trabalho nesta area.

## Funcionalidades utilizadas

**Cadastrar cliente**: voce adiciona um novo cliente no qual ira possuir nome, telefone e email

**Listar cliente**: ira mostrar todos o cliente cadastrado e seus dados

**Atualizar cliente**: funçao de alterar o nome, telefone e email de um cliente ja cadastrado, sendo buscado atraves do seu nome

**Remover cliente**: ira excluir um cliente da lista, buscado atraves do nome
